# Fari nella Tempesta

Gioco da tavolo cooperativo per due giocatori, online e gratuito. Partite da 15–20 minuti.

L'arcipelago sta affondando: recuperate insieme le quattro Lenti del faro e tornate al Molo prima che la marea si prenda tutto.

**Giocare:** apri la pagina, premi *Crea una partita* e manda il link d'invito all'altra persona. Nessuna registrazione.

Ispirato a L'Isola Proibita, Pandemic e Hanabi. Sincronizzazione tramite broker MQTT pubblici (EMQX, HiveMQ).
